# AI-Sliding 隐私政策

> 发布审核草稿，适用于 v1.2.0 的代码行为。尚未发布，也不代表商店旧版适用此说明。

## 网页文字与模型服务

AI-Sliding 在可访问的 HTTP(S) 网页上识别普通正文选区，以显示翻译或解释按钮。仅选中文字不会触发网络请求。输入框及可编辑区域内的选区不会触发该功能。

当你选择翻译或解释时，扩展将选中文字、对应提示词和目标语言随模型 ID 一起发送到你配置并授权的模型接口。该接口可能由你自己运行，也可能由外部服务商运行。如果你设置了 API 密钥，扩展会将它作为请求的认证信息发给该接口。连接测试只发送固定的测试文本和模型 ID，以及接口所需的认证信息，不发送网页选区。

扩展不会将你的浏览历史、整页网页内容或页面地址作为单独的请求字段发送，也没有单独的分析或广告上报接口。请勿选择或在提示词中写入口令、身份信息或其他不应交给模型服务处理的内容。

## 配置保存与模型结果

新版本使用当前 Chrome 配置文件的扩展本地存储保存接口地址、API 密钥、模型 ID、目标语言和自定义提示词。这些设置不再由扩展跨设备同步。本地存储不是专用的加密密钥库。旧版已经同步过的密钥在迁移到当前浏览器的本地配置后，扩展会尝试从旧同步设置中移除。

模型结果在当前网页的扩展界面中按纯文本显示。扩展不建立选区或结果的历史记录。你使用「复制」时，结果将写入系统剪贴板；剪贴板是否被设备或其他软件保留，不由扩展控制。

## 第三方服务与用户控制

远端模型接口必须使用 HTTPS；你也可以选择本机回环 HTTP 接口。由你选择的模型服务处理收到的请求，其数据保留或再利用方式由相应服务规则决定。本政策不对这些服务的处理方式作出承诺。

你可以在扩展设置中更换服务或清空密钥后保存，也可通过 Chrome 的扩展管理界面管理站点访问权限或卸载扩展。
