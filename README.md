# AI-Sliding 智能浏览器滑动助手

在网页上选中文字，点击「翻译」或「解释」，即可调用你自己配置的模型服务，并在原页面查看和复制结果。扩展使用 Chrome Manifest V3，不需要构建步骤。

## 安装与设置

1. 使用 Chrome 114 或更高版本。将下载包解压，打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。若下载的是仓库源码，选择 `chrome-extension-crx/`。
2. 打开扩展图标，填写支持 OpenAI 兼容 **Chat Completions** 的 API 地址和对应的模型 ID。地址可以是基础地址（如 `https://api.openai.com/v1`），也可以是完整的 `/chat/completions` 地址。远端服务必须使用 HTTPS；只有本机回环地址允许 HTTP，例如 `http://localhost:11434/v1`。不支持需要在 URL 中传入查询参数或身份凭据的接口。
3. 服务要求认证时，填写 API 密钥。若服务支持无密钥访问，可以留空。设置目标语言；需要时可在「自定义提示词」里调整翻译和解释的提示词。
4. 点击「保存设置」。Chrome 如提示允许访问该模型服务的主机，请核对地址后再授权。点击「测试连接」确认可用；测试会向你保存的服务发送固定文本，不会读取当前网页。模型服务可能对此请求计费。
5. 在支持访问的 HTTP(S) 网页上选中不超过 8,000 个字符的普通正文，点击「翻译」或「解释」。键盘可按 `Alt+Shift+S` 将焦点移至选区工具栏，按 `Esc` 关闭。浏览器内部页面和 Chrome Web Store 等受保护页面不可用。

## 从 v1.1.0 升级

同一扩展安装升级后，新版本会尝试读取旧同步设置，将其迁移到当前浏览器的扩展存储，并在本地保存成功后移除旧同步区中的密钥。配置和密钥不再跨设备同步；如果另一台设备迁移时同步区里的密钥已被移除，需在该设备重新填写。下载包作为独立扩展安装时，不会读取商店版的设置。

第一次使用或更换模型服务主机时，请打开设置重新保存，按 Chrome 提示授予接口访问权限。若旧 HTTP 地址不是本机回环地址，请改用服务的 HTTPS 地址。升级后已有网页可能需要刷新，才能加载新代码。

## 隐私与安全

- 仅选中文字不会发起网络请求。点击「翻译」或「解释」后，扩展将选中文字、相关提示词、目标语言和模型 ID 发给你配置的服务。输入框和可编辑区域的选区不会触发此操作。
- 扩展将配置和密钥存于当前 Chrome 配置文件内的扩展本地存储。该存储不是密钥保险库，不能防止拥有本机配置文件访问权的人读取；不要把密钥或私有接口地址贴到公开 issue、截图或代码中。
- 不要发送口令、身份信息或其他敏感文本。模型服务如何保存和使用请求数据，以该服务的政策为准。
- 模型生成内容按纯文本显示，不执行其中的 HTML 或脚本。

## 开发与测试

源代码在 `chrome-extension-crx/`，不依赖第三方构建工具。修改源码后，在 `chrome://extensions` 重新加载扩展并刷新测试页面。

运行核心逻辑测试：

```sh
node --test tests/core.test.cjs
node tests/browser-smoke.mjs --worker-only
```

如本机已安装 Playwright 和它的 Chromium，运行 `node tests/browser-smoke.mjs` 可测试浏览器界面；也可用 `CHROMIUM_PATH` 指向 Chrome/Chromium。此测试使用临时扩展副本和本机模拟接口，不调用付费模型，也不覆盖浏览器原生授权弹窗。

手动安装验证时，依次检查保存、测试连接、翻译、解释、复制、HTTP 错误提示、编辑区选区不触发，以及模型返回的 HTML 只按文本显示。
